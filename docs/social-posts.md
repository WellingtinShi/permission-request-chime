```text
I rebuilt Permission Request Chime as two Codex plugins:

macOS: permission-request-chime
Windows: permission-request-chime-windows

Same idea: when Codex asks for permission, play a local sound.

No screen watching.
No OCR.
Just Codex's PermissionRequest hook.

https://github.com/WellingtinShi/permission-request-chime
```

Reply with:

```text
Install marketplace:

codex plugin marketplace add WellingtinShi/permission-request-chime --ref v0.2.0

Then open the Codex plugin directory and install the version for your OS:

macOS: permission-request-chime
Windows: permission-request-chime-windows

Restart Codex and trust the hook when prompted.
```
