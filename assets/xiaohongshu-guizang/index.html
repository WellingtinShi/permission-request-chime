Why Two Versions

不同系统，
用不同命令。

01 / mac
macOS 用 afplay默认播放 Glass.aiff，走 /bin/sh。
02 / win
Windows 用 PowerShell优先播放 Windows 自带 .wav 文件。
03 / choose
只装一个版本按自己的系统选，不要两个一起装。

macOS · 03 permission-request-chime

macOS Version

macOS，
装这一版。

01
插件名不变permission-request-chime 继续留给 macOS。
02
本地系统音afplay 播放 Glass.aiff。
03
可以换声音启动 Codex 前设置 CODEX_PERMISSION_CHIME_SOUND。
macOS users: install permission-request-chime. 03/06
Windows · 04 permission-request-chime-windows

Windows Version

Windows，
装这一版。

01
新插件名permission-request-chime-windows。
02
PowerShell 提示音优先播放 C:\Windows\Media 里的 .wav。
03
自定义 .wav设置 CODEX_PERMISSION_CHIME_SOUND 指向声音文件。
Windows users: install permission-request-chime-windows. 04/06
